# Contact List

- Веб-приложение "Список контактов"

Поддерживает добавление, редактирование, удаление и поиск контактов.

## Технологический стек

- **Язык программирования:** JavaScript
- **API:** Browser APIs
- **Инструменты:** Webpack, NodeJS, Netlify
- **Хранилище:** LocalStorage

## Демо

- [Веб-версия](https://contact-list-sl.netlify.app/)

## Установка локально

```sh
npm i 
npm run start
```
